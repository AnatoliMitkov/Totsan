Manual Inbox QA

  2. Paste recovery.html into Supabase Authentication -> Email Templates -> Reset password / Recovery.
  3. Confirm production Auth email confirmations are enabled and OTP length is 6.
  4. Send Supabase test emails to Gmail and Outlook.
  5. Check desktop and mobile inbox rendering, including dark mode.
  6. Complete a real signup using both the email button and the 6-digit code.
  7. Use the resend action from /check-email and confirm the new email arrives.
